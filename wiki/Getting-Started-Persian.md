# شروع کار با MEDIA KOLFAT

**راهنمای فارسی نسخه ۱.۸.۰ — Windows**

MEDIA KOLFAT برای مرتب‌سازی عکس‌ها و ویدیوهای شما طراحی شده است. برای شروع، بهتر است از حالت راهنمای گام‌به‌گام (Guided Mode) و روش COPY استفاده کنید.

## پیش از شروع

۱. برنامه را از [Microsoft Store](https://apps.microsoft.com/detail/9p0x091t7mv4?ocid=webpdpshare) یا [نصاب رسمی GitHub برای ویندوز](https://github.com/1n50mn14c933k/MEDIA_KOLFAT/releases/download/v2.0.0/MEDIA_KOLFAT_2.0.0_Setup.exe) نصب کنید. نسخه GitHub به‌روزرسانی خودکار Microsoft Store را دریافت نمی‌کند.  
۲. از عکس‌ها و ویدیوهای مهم خود روی یک فضای ذخیره‌سازی جداگانه نسخهٔ پشتیبان تهیه کنید.  
۳. از اتصال هارد اکسترنال یا مسیر شبکه و کافی بودن فضای مقصد مطمئن شوید.  
۴. ابتدا برنامه را با چند فایل آزمایشی اجرا کنید.

## نخستین مرتب‌سازی

۱. برنامه را باز کنید و **Guided Mode** را انتخاب کنید.  
۲. پوشهٔ عکس‌ها و ویدیوها را به‌عنوان منبع انتخاب کنید.  
۳. پس از شناسایی فایل‌ها، پیش‌نمایش و اطلاعات تاریخ را بررسی کنید.  
۴. محل ذخیره‌سازی و الگوی مرتب‌سازی را انتخاب کنید.  
۵. برای حفظ فایل‌های اصلی، **COPY** را انتخاب کنید.  
۶. پیشرفت عملیات را بررسی کرده و منتظر پایان کار بمانید.  
۷. فایل‌های مقصد و گزارش عملیات را بررسی کنید.

## حالت پیشرفته

در **Advanced Mode**، افزون بر COPY، گزینهٔ **MOVE** نیز در دسترس است. MOVE محل فایل‌های اصلی را تغییر می‌دهد؛ بنابراین فقط پس از تهیهٔ پشتیبان و بررسی دقیق مبدأ و مقصد از آن استفاده کنید.

## امکانات نسخهٔ ۱.۸.۰

کنترل‌های Pause، Resume و Cancel، نمایش جزئیات پیشرفت، بهبود ایمنی MOVE و اصلاح انتخاب «Select All Visible» از ویژگی‌ها و اصلاحات این نسخه هستند.
