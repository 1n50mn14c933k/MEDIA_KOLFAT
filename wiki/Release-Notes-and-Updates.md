# Release Notes and Updates

**Current documented version:** MEDIA KOLFAT **1.8.0**  
**Microsoft Store package:** **1.8.0.0**  
**Published:** October 19, 2026

## What's new in 1.8.0?

- Guided Mode emphasizes safe COPY; Advanced Mode supports COPY and MOVE.
- Pause, Resume and Cancel provide improved control.
- Progress shows the current file, processing stage, completed items and percentage.
- Improved hidden/system file visibility, including network-drive cases.
- Stronger MOVE safeguards, better background activity indication and error handling.
- Fixed Select All Visible in Browse Library.

For the complete list, see the [1.8.0 release notes](https://github.com/1n50mn14c933k/MEDIA_KOLFAT/blob/main/release-notes/v1.8.0.md) and [public changelog](https://github.com/1n50mn14c933k/MEDIA_KOLFAT/blob/main/CHANGELOG.md).

## Install and update

Use the [official Microsoft Store listing](https://apps.microsoft.com/detail/9p0x091t7mv4?ocid=webpdpshare). GitHub source archive downloads are **not production Windows installers**.
