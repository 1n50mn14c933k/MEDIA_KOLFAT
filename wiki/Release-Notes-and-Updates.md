# Release Notes and Updates

**Current documented version:** MEDIA KOLFAT **2.0.0**  
**Microsoft Store package:** **2.0.0.0**  
**Published:** October 27, 2026

## What's new in 2.0.0?

- File Type Selection with file-extension counts and optional Other Files.
- Seven conditional destination folders, created only for relevant categories.
- Improved COPY/MOVE behavior for local and SMB/NAS network operations.
- Improved symbolic-link handling and file-operation safety.
- English, Persian (RTL), German and Spanish interface support.
- Refined interface and branding.
- An independent GitHub Windows x64 EXE installer alongside the Store edition.

For details, see the [2.0.0 release notes](https://github.com/1n50mn14c933k/MEDIA_KOLFAT/releases/tag/v2.0.0) and [public changelog](https://github.com/1n50mn14c933k/MEDIA_KOLFAT/blob/main/CHANGELOG.md).

## Install and update

- [Official Microsoft Store](https://apps.microsoft.com/detail/9p0x091t7mv4?ocid=webpdpshare) for Store-managed installations and updates.
- [Official GitHub Windows x64 EXE](https://github.com/1n50mn14c933k/MEDIA_KOLFAT/releases/download/v2.0.0/MEDIA_KOLFAT_2.0.0_Setup.exe) and [SHA-256 checksum](https://github.com/1n50mn14c933k/MEDIA_KOLFAT/releases/download/v2.0.0/MEDIA_KOLFAT_2.0.0_SHA256.txt) for direct downloads. The EXE does not receive Microsoft Store-managed updates.

The GitHub EXE is currently unsigned. Windows may show an unknown-publisher warning. Do not disable Windows security protections. GitHub's automatic source-code archives are not installers.

Historical releases remain available under [GitHub Releases](https://github.com/1n50mn14c933k/MEDIA_KOLFAT/releases).
