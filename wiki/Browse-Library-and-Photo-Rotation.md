# Browse Library and Photo Rotation

Browse Library lets you review media and adjust photo orientation without using a professional editing suite.

## Browse your media

- Open **Browse Library** and navigate to the images you want to inspect.
- Verify the displayed preview and selection before changing several photos at once.
- If thumbnails do not appear as expected, see [[Troubleshooting and FAQ|Troubleshooting-and-FAQ]].

## Photo rotation

Available actions include **Rotate Left**, **Rotate Right**, **180°** and **Undo**, with support for selecting multiple photos and performing batch rotations.

1. Select a photo.
2. Choose the desired direction or 180° rotation.
3. Inspect the visual result.
4. For multiple files, select the intended items, verify the selection and apply the batch action.
5. Use the available Undo control if a rotation needs reversing, while the applicable undo state remains available.

### About Select All Visible

The application includes the fix for **Select All Visible** behavior. It is intended for **currently visible items**, not necessarily every file in the entire library or on other pages. Check the selection count and thumbnails before running a batch action.

### Good habits

- Try a single image first.
- Double-check orientation for portrait phone photos.
- Do not assume an Undo operation is a substitute for an independent backup.
- If your library contains valuable originals, preserve backups before mass edits.
