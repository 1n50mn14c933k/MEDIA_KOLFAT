## Helping users of different experience levels

MEDIA KOLFAT offers Guided Mode for step-by-step workflows and Advanced Mode for additional choices. Start in Guided Mode and use COPY while learning the application.

If you encounter text clipping, layout direction issues, unclear labels, keyboard-navigation difficulties or other accessibility barriers, describe the affected screen and your Windows version in [Discussions](https://github.com/1n50mn14c933k/MEDIA_KOLFAT/discussions).

## Request another language

Which language would help you or your family most? Explain whether you need:

- Translated interface labels
- Localized help and tutorials
- Right-to-left layout support
- Larger text or simpler terminology
- Keyboard or other accessibility improvements

Suggestions are welcome; requests are **not promises** that a language will be released on a specific date. Avoid sharing personal files or sensitive data publicly.
