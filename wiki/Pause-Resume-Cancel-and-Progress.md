# Pause, Resume, Cancel and Progress Tracking

Version **1.8.0** improves control over photo and video organization.

## Operation controls

- **Pause:** Request a temporary stop so you can inspect status before proceeding.
- **Resume:** Continue a paused operation through the app.
- **Cancel:** Request that the running operation stop. Always review the result afterward.

These controls should not be confused with an automatic rollback. An operation can have completed some files before a pause, cancellation or interruption.

## Progress information

MEDIA KOLFAT 1.8.0 can display:

- Current file being processed
- Current processing stage
- Count of completed items
- Overall progress percentage
- Activity indication while background work continues

Progress may change unevenly because files vary in size and processing complexity.

## If the app is interrupted

1. Do not delete or overwrite source files.
2. Reconnect any unavailable drives or network shares.
3. Review the application's state, destination contents and operation report.
4. Verify which files completed before starting new operations.
5. For MOVE, check **both** source and destination; do not infer that every original transferred successfully.
6. Keep your backup intact until you are satisfied with the result.

For problems with permissions, hidden file attributes or incomplete output, see [[Troubleshooting and FAQ|Troubleshooting-and-FAQ]].
