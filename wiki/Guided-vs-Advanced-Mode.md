# Guided Mode vs Advanced Mode

MEDIA KOLFAT 2.0.0 provides **Guided** and **Advanced** experiences to serve different needs.

| | Guided Mode | Advanced Mode |
|---|---|---|
| Best for | New users and safety-first organization | Users who want additional control |
| Primary organization option | **COPY** | **COPY or MOVE** |
| Source files | COPY aims to retain originals | MOVE transfers originals; extra care required |
| Workflow | Guided steps and explanations | More explicit choices and controls |
| Recommendation | Start here | Use after understanding the consequences |

## Choose Guided Mode when...

- You're organizing a library for the first time.
- You want to understand the selected source, destination and outcome.
- You prefer to preserve source files while creating organized copies.
- You're helping a family member manage an existing photo collection.

## Choose Advanced Mode when...

- You understand the difference between COPY and MOVE.
- You need to transfer originals into a new destination.
- You have independently backed up irreplaceable files and can validate the results.
- You are comfortable reviewing operation reports and any warnings.

## Important: MOVE is not just another type of COPY

MOVE changes where the original files are stored. Unexpected interruptions, inaccessible drives or insufficient destination space may affect the operation. MEDIA KOLFAT retains safeguards, but **no software feature replaces an independent backup**.

If unsure, choose **Guided Mode + COPY**.
