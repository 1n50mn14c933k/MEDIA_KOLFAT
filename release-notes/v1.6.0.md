MEDIA KOLFAT **1.6.0** adds new workflows and more control over media organization.

**Published:** October 1, 2026  
**Platform:** Windows  
**Microsoft Store package version:** `1.6.0.0`  
**Languages:** English, Persian (RTL)

This release introduced Guided and Advanced experiences, MOVE support, richer library information and improved photo rotation.

## ✨ What's New

- 🧭 **Guided & Advanced Modes:** Added two experiences tailored to different user needs.
- 📦 **MOVE Mode:** Added an option for organizing files while transferring originals.
- 📝 **COPY & MOVE Reports:** Added automatic text reports for organization operations.
- 📊 **Library Overview:** Added media, health, duplicate and organization information.
- 🕘 **Activity History:** Added history for completed scans and organization operations.
- 🔐 **Privacy Information:** Added in-app information about privacy and local processing.
- 🔄 **Batch Photo Rotation:** Improved manual rotation with multi-select and batch operations.
- ↩️ **Rotation & Undo:** Added Rotate Left, Rotate Right, 180° and batch Undo in Browse Library.
- 🖼️ **Browse Library:** Improved layout and usability for library browsing.
- 🌍 **English & Persian:** Improved localization, including Persian right-to-left presentation.
- ⚡ **Stability & Performance:** Improved application safety, interface consistency and performance.
