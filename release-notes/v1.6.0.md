## ✨ What's New

- 🧭 Added **Guided and Advanced experiences** for different user needs
- 📦 Added **MOVE mode** for safely organizing files while transferring originals
- 📝 Added automatic **COPY and MOVE operation reports**
- 📊 Added **Library Overview** with useful media, health, duplicate, and organization information
- 🕘 Added **Activity History** for completed scans and organization operations
- 🔐 Added **Privacy & Local Processing** information
- 🔄 Improved manual photo rotation with **multi-select and batch rotation**
- ↩️ Added **Rotate Left, Rotate Right, 180° and batch Undo** directly in Browse Library
- 🖼️ Improved **Browse Library** layout and usability
- 🌍 Improved support for **English and Persian (RTL)**
- ⚡ Numerous stability, safety, UI, and performance improvements
