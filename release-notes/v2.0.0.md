MEDIA KOLFAT **2.0.0** brings improved file organization, expanded language support, safer network operations and an official direct-download EXE installer alongside the Microsoft Store edition.

**Published:** October 27, 2026  
**Platform:** Windows x64  
**Microsoft Store package version:** `2.0.0.0`  
**Languages:** English, Persian (RTL), German, Spanish

Version 2.0.0 makes it easier to choose what to organize, improves COPY and MOVE behavior for local and network storage, and refines the MEDIA KOLFAT experience.

## ✨ What's New

- 🗂️ **File Type Selection:** Choose the file types to organize, with file-extension counts and category controls. Photos and videos remain selected by default; Other Files is optional.
- 📁 **Seven Smart Destination Folders:** Create only the folders required for the selected files: **SORTED PHOTOS**, **SORTED VIDEOS**, **DUPLICATED PHOTOS**, **DUPLICATED VIDEOS**, **PHOTOS WITH UNKNOWN DATE**, **VIDEOS WITH UNKNOWN DATE**, and **OTHER FILES**.
- 📦 **Expanded COPY & MOVE:** Organize optional Other Files as well as media. Guided Mode continues to use COPY by default; Advanced Mode offers COPY and MOVE with existing verification-before-deletion safeguards.
- 🌐 **Network Storage Improvements:** Corrected SMB/NAS-to-NAS MOVE handling, with large-library NAS MOVE testing involving more than 20,000 photos.
- 🌍 **Four Languages:** English and Persian (including right-to-left layout), now joined by **German** and **Spanish**.
- 🔐 **Safer File Handling:** Improved symbolic-link handling and file-operation safety.
- ✨ **Interface & Branding:** Refined UI/UX, localization, and MEDIA KOLFAT logo presentation.
- 🖥️ **Direct Windows Installer:** A Windows x64 EXE installation option in addition to the Microsoft Store MSIX version.
