# MEDIA KOLFAT 2.5.0 | Windows 🪟

**Version:** 2.5.0 (Windows package: `2.5.0.0`, if confirmed by the installer)  
**Platform:** Windows x64  
**Release channel:** Stable  
**Distribution:** GitHub Windows installer; Microsoft Store availability is managed separately  
**Price:** Free forever

MEDIA KOLFAT 2.5.0 focuses on making photo and video organization easier to navigate, easier to discover, and easier to review, while retaining user control over files.

## ✨ What's new

- 🧭 **Guided and Advanced workflows:** Clearer navigation and more consistent organization workflows for new and experienced users.
- 🔎 **Smarter media discovery:** Guided folder discovery and a way to view all available folders when automatic recommendations aren't enough.
- 📅 **Timeline and Search:** Find media by date, including content with unknown dates, and narrow results using available filters.
- 📊 **Improved operation reports:** Readable offline HTML reports alongside existing text and export formats where available.
- 📂 **COPY and MOVE workflow improvements:** More explicit readiness information, navigation feedback, and file-operation safeguards. Guided users should prefer COPY; Advanced MOVE requires care with originals.
- 🌍 **Localization:** Continued support for English, German, Spanish, and Persian (including right-to-left display).
- 🛠️ **Usability and stability:** Refinements across navigation, spacing, folder selection, and operation feedback.

## ⬇️ Official downloads

The Windows installer and its matching SHA-256 checksum will appear in the **Assets** section of this release once uploaded and verified.

- **GitHub:** Download the Windows x64 installer from the Assets below.
- **Microsoft Store:** [MEDIA KOLFAT on Microsoft Store](https://apps.microsoft.com/detail/9p0x091t7mv4) (Store version may differ from this GitHub release).

**Integrity check (PowerShell):**

```powershell
Get-FileHash -Algorithm SHA256 "PATH_TO_DOWNLOADED_INSTALLER.exe"
```

Compare the result with the checksum published under Assets. The standalone GitHub installer may not have Microsoft Store signing; Windows may show a publisher or SmartScreen warning. Download only from official sources and verify the checksum.

## 🔐 Privacy and file safety

MEDIA KOLFAT is local-first: normal photo and video organization does not require uploading your library to KOLFAT servers. Keep independent backups of irreplaceable files and review source, destination, and COPY/MOVE settings before operations.
