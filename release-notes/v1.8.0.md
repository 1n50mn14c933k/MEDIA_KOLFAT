MEDIA KOLFAT **1.8.0** is a Windows update focused on safer operations and usability.

**Published:** October 19, 2026  
**Platform:** Windows  
**Microsoft Store package version:** `1.8.0.0`  
**Languages:** English, Persian (RTL)

This update improves COPY and MOVE controls, progress visibility, file safety, library selection and overall reliability.

## ✨ What's New

- 📦 **Improved COPY & MOVE:** Guided Mode focuses on safe copying, while Advanced Mode provides both COPY and MOVE options.
- ⏯️ **Pause, Resume & Cancel:** Greater control over photo and video organization, with improved handling of interrupted operations.
- 📊 **Enhanced Progress Tracking:** View the current file, processing stage, completed items and overall progress percentage.
- 👁️ **Improved File Visibility:** Fixed hidden and system file attributes affecting organized media, including files stored on network drives.
- 🔐 **Stronger File Safety:** Additional safeguards for MOVE operations to help protect original files from accidental deletion.
- ✨ **Better Visual Feedback:** Improved animated activity indicator during background processing.
- 🖼️ **Library Improvements:** Fixed the **Select All Visible** behavior in Browse Library.
- 🛠️ **Stability & Reliability:** Improved error handling, automatic reporting and overall application stability.
