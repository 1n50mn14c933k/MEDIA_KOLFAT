MEDIA KOLFAT **1.0.0** is the first public Windows release.

**Published:** September 10, 2026  
**Platform:** Windows  
**Microsoft Store package version:** `1.0.0.0`  
**Languages:** English

The first public release introduced practical, predictable photo and video organization for Windows.

## ✨ What's New

- 🖼️ **Photo & Video Library:** Manage photo and video collections on Windows.
- 📂 **Media Sources:** Manage the folders and locations containing your media.
- 🏷️ **Metadata & Dates:** Handle photo and video metadata and available date information.
- 📅 **Date-Based Organization:** Organize media using the available date information.
- ❓ **Unknown-Date Handling:** Handle media without valid EXIF or date metadata.
- 👁️ **Thumbnails & Previews:** Generate thumbnails and previews for library browsing.
- ⚡ **Large-Library Performance:** Improvements for working with larger media collections.
- 🌙 **Dark Interface:** A dedicated dark-themed application experience.
- 🔐 **Local Processing:** Organize media locally on your Windows computer.
