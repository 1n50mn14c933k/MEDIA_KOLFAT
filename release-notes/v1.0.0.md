MEDIA KOLFAT **1.0.0** is available for Windows through the Microsoft Store.

**Published:** September 10, 2026  
**Platform:** Windows

The first public production release introduced practical, predictable photo and video organization on Windows.

## ✨ What's New

- Photo and video library management
- Media source management
- Metadata and date handling
- Date-based media organization
- Handling of media without valid EXIF/date information
- Thumbnail and preview generation
- Large-library performance improvements
- Dedicated dark user interface
- Local-first media processing

## 🔐 Privacy and Local Processing

MEDIA KOLFAT is designed for local photo and video management. Normal organization workflows process your media on your Windows computer without requiring your library to be uploaded to KOLFAT servers.
