# 🐧 MEDIA KOLFAT 2.4.0 for Linux | Public Beta

**Version:** 2.4.0 Linux Public Beta  
**Platform:** Linux x64 / AMD64  
**Distribution:** GitHub AppImage (portable executable)  
**Release channel:** **Pre-release — experimental**  
**Price:** Free

MEDIA KOLFAT brings local photo and video organization to Linux. This is a separate, experimental Linux build; the stable Windows 2.0.0 release remains unchanged.

## ✨ Available Linux Beta functionality

- 🖼️ **Guided COPY:** Organize photos and videos while retaining original source files.
- 📅 **Date / EXIF organization:** Sort supported media using available capture dates and metadata.
- 🔍 **Duplicate Finder:** SHA-256-based duplicate grouping.
- 📂 **Library browsing and source selection:** Work with media folders and manually selected sources.
- 🛡️ **Safety-focused operations:** Filesystem containment, symlink rejection, collision and cancellation safeguards, and operation reports were exercised in prior Linux testing.

Functionality can vary by environment. The list describes the Linux Beta feature set; it does not claim every feature has been freshly tested with this exact 2.4.0 AppImage.

## ⚠️ Important limitations and testing disclosure

- **MOVE is disabled on Linux, including Advanced Mode.** COPY keeps original files; do not expect Linux MOVE or source deletion.
- **The 2.4.0 AppImage has NOT been launched on a native Ubuntu 26.04 desktop.** Its WSLg-based tests passed, but WSLg validation is not a substitute for native graphical desktop validation.
- **Earlier Linux version only:** A previous Linux Beta successfully launched on native Ubuntu 26.04.1 LTS x64 and completed a real Guided COPY operation with 101 sample photos. That result does **not** demonstrate native execution of the 2.4.0 AppImage.
- Some Linux UI behavior (including Reset Settings to Default) and compatibility across distributions or desktop environments remain unverified for this specific AppImage.
- This release is **experimental, not production-stable**. Keep independent backups of irreplaceable media and review COPY reports.

## ⬇️ Linux AppImage download and integrity

The distribution for this Linux Beta is **one x64 `.AppImage` file and its matching SHA-256 checksum file**, not a Debian package, portable `.tar.gz` bundle, or a new Windows installer.

**Attachment status:** The two exported and verified files must be uploaded to this release's **Assets** section. **Until both files are present, there is no official 2.4.0 binary download here.** GitHub's automatically generated “Source code” archives are **not** executable Linux installers.

After the AppImage and checksum appear under **Assets**, download both files, verify the AppImage against the provided SHA-256 checksum, then on a compatible Linux x64 desktop:

```bash
chmod +x ./<downloaded-file>.AppImage
./<downloaded-file>.AppImage
```

Replace `<downloaded-file>` with the exact verified AppImage filename. Never bypass signature, security or filesystem protections to make an untrusted file run.
