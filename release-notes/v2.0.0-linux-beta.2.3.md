# 🐧 MEDIA KOLFAT 2.0 for Linux | Public Beta

**Version:** 2.0.0 Linux Beta 2.3  
**Platform:** Linux x64 / AMD64  
**Channel:** Experimental pre-release  
**Price:** Free

MEDIA KOLFAT is coming to Linux! This early public Beta brings photo and video organization to Linux with an emphasis on local processing, transparent reporting and preserving original media.

## ✨ Available features

- **Guided COPY** for photos and videos, including manually selected files and folders
- **EXIF-based date organization** into structured directories
- **Duplicate Finder** with SHA-256 duplicate grouping
- **Library browsing**, media discovery and the familiar dark MEDIA KOLFAT interface
- **Collision and cancellation safeguards**, operation reports and original-file retention

## ⚠️ Important Linux Beta limitations

- **MOVE is disabled on Linux, including Advanced Mode.** COPY is the supported organization method and keeps original files.
- **Reset Settings to Default and some other Linux UI features may not work correctly** in this Beta.
- **Debian package dependencies and distribution compatibility vary**; Ubuntu 26.04.1 GUI execution has been tested using the portable archive.
- This is **experimental software**, not a stable or production-ready release. Always keep a separate backup of irreplaceable media.

## 🧪 Testing performed

- Native Ubuntu 26.04.1 LTS x64: real graphical startup and Guided COPY of 101 sample photos succeeded.
- Automated tests covered indexed and manually approved COPY, date/EXIF preservation, duplicate grouping, filesystem containment, symlink rejection, source retention, collisions and cancellation.
- MOVE source deletion was **not** enabled or tested on Linux.

## ⬇️ Download status

**The GitHub pre-release announcement is published; portable `.tar.gz`, Debian `.deb`, and SHA-256 checksum attachments are pending upload.** Do not use GitHub's automatically generated source archives as app installers.

Once uploaded, download the binary files from the **Assets** section below and verify them against their provided checksums. Linux binary assets must match this Beta version.
