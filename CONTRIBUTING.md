# Contributing to MEDIA KOLFAT

Thank you for helping improve MEDIA KOLFAT.

MEDIA KOLFAT is proprietary software. This public repository is used for product information, public documentation, release transparency and community feedback; it is **not** the application source repository.

## You can contribute by

- Reporting reproducible application bugs
- Suggesting useful features or workflow improvements
- Providing clear usability feedback
- Suggesting corrections to public documentation
- Reporting security issues privately through the process in [SECURITY.md](SECURITY.md)

## Bug-report quality

Good reports are specific, reproducible and sanitized of sensitive information.

Please include the MEDIA KOLFAT version, OS and version (including Linux distribution and desktop environment where relevant), steps to reproduce, expected behavior and actual behavior whenever applicable.

Search existing Issues before creating a duplicate.

## Feature requests

Explain the user problem or workflow first.

Feature requests are considered product input and do not imply a commitment to implement or release the requested functionality.

## Please do not submit

- Decompiled or reverse-engineered proprietary application source
- Credentials, secrets, tokens or signing material
- Personal media or private user information
- Public vulnerability disclosures for unpatched issues
- Production installers from unofficial sources

## Source contributions

The proprietary MEDIA KOLFAT application source code is maintained separately in a private repository.

Application-source pull requests are therefore not accepted through this public repository.

## Code of conduct

Keep technical discussions professional, relevant and focused on improving the product or documentation.
