## Bug reports

Before opening a new issue, search existing issues to avoid duplicates.

A useful bug report includes:

1. MEDIA KOLFAT version
2. Windows version
3. Steps to reproduce
4. Expected result
5. Actual result
6. Relevant sanitized logs or screenshots

Remove personal names, private file paths, media content, credentials and other sensitive information before posting.

## Common troubleshooting information

When diagnosing a problem, first verify:

- MEDIA KOLFAT is up to date through its original distribution channel (Microsoft Store or GitHub EXE)
- Windows is up to date
- The affected media source is still accessible
- The application can access the relevant folders
- The issue can be reproduced consistently
- Any screenshot or log is sanitized before sharing

More detailed troubleshooting guidance is maintained at https://kolfat.app/support/.

## Working with version 2.0.0

- **Guided or Advanced:** choose the experience that suits your level of control.
- **COPY or MOVE:** use COPY if you want to retain your originals at the source. Select MOVE intentionally when you want originals transferred; verify the destination and retain a backup of important media.
- **Pause, Resume and Cancel:** use these controls to manage organization runs, and check progress details to understand the current processing stage.
- **Operation reports:** check the automatic COPY or MOVE report after an organization operation.
- **File visibility:** organized files should retain normal visibility; if attributes or network drives cause unusual behavior, review the operation report before changing originals.
- **Library Overview and Activity History:** review media information and past scans or organization activity.
- **Photo rotation:** Rotate Left, Rotate Right, 180° and batch Undo are available in Browse Library, alongside multi-select and batch rotation.
- **Language:** English, Persian (Farsi) with RTL, German and Spanish.
- **File Type Selection:** Select relevant categories and optional Other Files; only needed destination folders are created.
- **Network MOVE:** Check source/destination access and the report for SMB/NAS transfers.

For unexpected organization results, stop further file operations until you have checked the source, destination and operation report. Do not delete backups while investigating.
