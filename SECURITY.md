# MEDIA KOLFAT Security Policy

Security reports are taken seriously. Please help protect MEDIA KOLFAT users by reporting suspected vulnerabilities privately.

## Reporting a vulnerability

**Do not open a public GitHub issue for a suspected security vulnerability.**

Preferred reporting methods:

1. Use GitHub's private vulnerability reporting / security advisory mechanism when available for this repository.
2. If that mechanism is unavailable, use the official KOLFAT support channel at https://kolfat.app/support/ and clearly identify the message as a security report.

Provide enough information to reproduce and assess the issue without including unnecessary personal data.

Useful information includes:

- Affected MEDIA KOLFAT version
- Windows version
- Vulnerability type and affected workflow
- Reproduction steps or a minimal proof of concept
- Security impact
- Any known mitigations

## Responsible disclosure

Please allow reasonable time for investigation and remediation before publicly disclosing an unpatched vulnerability.

Do not intentionally access, modify or destroy another person's data as part of security research.

## Never publish publicly

Do not publish:

- Exploit details for an unpatched MEDIA KOLFAT vulnerability
- Credentials, access tokens, passwords or private keys
- Personal media or private user data
- Sensitive file-system paths or account information
- Code-signing certificates, keys or signing material
- Private proprietary source code

## Supported production release

The current publicly released version is **MEDIA KOLFAT 1.6.0** (Microsoft Store package **1.6.0.0**).

Users should keep MEDIA KOLFAT updated through the Microsoft Store so they receive the latest production fixes and improvements. Check [GitHub Releases](https://github.com/1n50mn14c933k/MEDIA_KOLFAT/releases) for current release information.

Microsoft Store:
https://apps.microsoft.com/detail/9p0x091t7mv4?ocid=webpdpshare

Pre-release or private development builds are not supported production versions.

## Official software distribution

The Microsoft Store is the authoritative distribution and update channel for MEDIA KOLFAT production builds.

Do not trust production installers from third-party mirrors unless KOLFAT explicitly identifies that source as official.
