# 🐧🍎 Would You Use MEDIA KOLFAT on Linux or macOS?

MEDIA KOLFAT currently runs on **Windows**. Linux and macOS have been mentioned as possible longer-term directions **if adoption and demand justify the work**.

Would a Linux or macOS version help you? Tell us which operating system and hardware you use, whether your library is local or on a NAS, and which workflow you'd most want to see supported.

This is an interest survey, **not an announced port or timeline**.
