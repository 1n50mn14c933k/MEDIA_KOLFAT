# 🧪 MEDIA KOLFAT 2.0.0 — Share Your Experience

MEDIA KOLFAT **2.0.0** introduces improvements to file selection, organization, network operations, localization and Windows distribution:

- 🗂️ **File Type Selection:** Select files with extension counts and optional Other Files.
- 📁 **Conditional Destination Folders:** Seven destination categories created only when needed.
- 📦 **COPY & MOVE:** Additional organization support for optional Other Files.
- 🌐 **SMB/NAS MOVE:** Improved network MOVE reliability for large collections.
- 🌍 **Languages:** English, Persian (RTL), German and Spanish.
- 🔐 **Safer Operations:** Improved symbolic-link and file safety.
- 🖥️ **Direct EXE:** Windows x64 installer alongside Microsoft Store delivery.

Have you tried version 2.0.0? What works well, and what needs improvement?

For reproducible defects, please use [GitHub Issues](https://github.com/1n50mn14c933k/MEDIA_KOLFAT/issues) and include your Windows version, MEDIA KOLFAT version, steps and sanitized evidence. **Do not share personal media, private paths or credentials.**
